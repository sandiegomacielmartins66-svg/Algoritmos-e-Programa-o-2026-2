- Resolução de problemas com lógica de programação

## ▶️ Como executar

1. Tenha o **JDK (Java Development Kit)** instalado.
2. Abra o arquivo do exercício desejado em sua IDE ou editor.
3. Compile e execute a classe correspondente.

Exemplo pelo terminal:

```bash
javac Main.java
java Main
```

> Alguns exercícios foram escritos durante as primeiras aulas e podem utilizar recursos de versões recentes do Java ou precisar de pequenos ajustes para compilar em versões mais antigas. O objetivo é preservar o histórico de aprendizagem.
